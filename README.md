# University projects (showcase)

Overview of coursework and thesis projects from my Bachelor's studies at the Kyrgyz-Russian Slavic University (2019–2022). This repository is a **showcase only**: it describes what was built and what I learned; it does not contain the source code.

| Project | Period | Stack |
|---|---|---|
| [Pascal chess with an AI bot](#pascal-chess-with-an-ai-bot) | 2019–2020 | Pascal, algorithms, graphics |
| [Mini Doom in C++](#mini-doom-in-c) | 2020–2021 | C++, OpenGL, ray casting |
| [Web data analytics monitor](#web-data-analytics-monitor) | 2021 | Java, Spring Boot, PostgreSQL |

## Pascal chess with an AI bot
Course project (Programming Fundamentals). A complete chess game in Pascal with a graphical interface.
- Chess rule engine with move validation
- Game-state management
- Computer opponent using minimax with alpha-beta pruning, with adjustable difficulty

## Mini Doom in C++
Course project (Computer Graphics & Game Development). A small recreation of the classic Doom.
- Custom 3D engine written from scratch in C++ with ray-casting rendering
- Enemy AI with pathfinding and behaviour
- Collision detection, several levels, weapons

## Web data analytics monitor
Course project (Web Development & Analytics). A web-based monitoring system built on Spring Boot.
- Real-time data collection and processing pipeline
- Interactive charts, automated scheduled reports
- Responsive web interface
